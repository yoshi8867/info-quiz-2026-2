# 정보 과목 2학기 퀴즈

용산고등학교 정보 과목 2학기 활동용 페이지입니다.

학생은 교내 각 장소에 붙은 QR 을 태블릿으로 찍어 들어옵니다.
페이지마다 **팀코드**와 **입장코드**가 있어야 문제가 열리고,
문제를 맞혀야 다음 장소와 그곳의 입장코드가 나옵니다.

입장코드는 팀마다 다릅니다. 그래서 한 팀이 다른 팀에 코드나 정답을 알려 줘도
그 팀의 페이지는 열리지 않습니다.

문제 본문과 정답은 이 저장소 어디에도 평문으로 들어 있지 않습니다.
각 페이지의 내용은 「팀코드 + 입장코드」로만, 다음 안내는 「팀코드 + 정답」으로만
풀리도록 잠겨 있습니다. 주소를 알아도 코드 없이는 아무것도 볼 수 없으므로
공개해 두었습니다.
